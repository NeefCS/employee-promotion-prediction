# Employee Promotion Prediction

## Overview
This project predicts employee promotion outcomes using Machine Learning techniques.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Logistic Regression

## Key Findings
The initial model achieved 85% accuracy but failed to identify the minority class due to class imbalance.

To address this issue:
- Classification Report was analyzed
- Confusion Matrix was reviewed
- class_weight='balanced' was applied

## Results
The project demonstrates why accuracy alone can be misleading in imbalanced classification problems.
